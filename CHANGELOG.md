# Changelog

All notable changes to HundredX will be documented in this file.

## [1.0.0] - 2024-01-26

### Added
- Initial release of HundredX
- User authentication (sign up, login)
- Buy/Sell trading functionality
- Portfolio tracking
- Real-time price feeds
- Social trading features (follow, feed)
- Leaderboard system
- Price alerts
- User profiles
- Trading history
- Token discovery and trending
- WebSocket support for real-time updates
- Solana blockchain integration

### Backend
- Express.js REST API
- PostgreSQL database
- JWT authentication
- Solana Web3.js integration
- Real-time updates with Socket.IO

### Frontend
- iOS app (Swift + SwiftUI)
- Android app (Kotlin + Jetpack Compose)
- User authentication screens
- Trading interface
- Portfolio dashboard
- Social feed
- Leaderboard

### Documentation
- API documentation
- Setup guides
- Contributing guidelines
